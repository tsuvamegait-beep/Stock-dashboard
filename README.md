# Stock-dashboard
## 일별 환율 탭 (환차손익 계산)
1. `apps_script.gs.txt`의 새 코드를 Apps Script에 붙여넣고 **새 버전으로 다시 배포**합니다.
2. 편집기 위쪽 함수 선택에서 **setupFx**를 한 번 실행합니다. 시트에 "환율" 탭이 생기고 달러·엔 일별 환율이 자동으로 채워집니다.
3. 대시보드 계좌 관리 탭의 "일별 환율" 카드에서 **환율 불러오기**를 누릅니다(이후에는 열 때마다 자동).
- 해외 종목의 원화 원가·실현손익·배당은 거래일 환율로, 연초 보유분은 전년 12/31 환율로 계산합니다. 환율 기록이 없으면 현재 환율로 환산합니다.

## RS 탭 (상대강도)
- 보유 종목과 기초 지수(코스피, S&P 500, 나스닥 등)의 일별 종가를 Apps Script가 구글 시트의 GOOGLEFINANCE로 계산해 돌려줍니다(숨김 탭 `_RS계산` 사용).
- `apps_script.gs.txt` 새 코드를 붙여넣고 **새 버전으로 다시 배포**해야 동작합니다. 과거 시세는 하루 한 번 브라우저에 보관합니다.
- 종목 티커는 시세 시트의 종목코드에서 자동으로 만듭니다(국내 `KRX:코드`, 일본 `TYO:코드`, 미국 티커 그대로). 틀리면 RS 탭의 "구글 티커" 칸에서 고칠 수 있습니다.

## 종목분석 탭 (주가 / 관련 종목 비교 / 신용잔고 비교)
- 종목을 고르고 보기를 선택합니다. 기본은 **주가**(선택한 종목의 주가와 기간 최고·최저만). **신용잔고 비교**는 주가(왼쪽 눈금)와 코스피 신용융자 잔고(오른쪽 눈금, 점선)를 겹쳐 그리고, **관련 종목 비교**는 아래 설명대로 수익률을 겹칩니다. 기간은 1개월·3개월·6개월·YTD·1년.
- 신용잔고 자동 갱신은 **신용잔고 비교** 보기를 그날 처음 열 때 실행됩니다.
- **신용잔고 자동 수집**: 동기화(Apps Script)를 설정했다면 신용잔고 비교 보기를 하루 처음 열 때, 또는 "금투협에서 자동 갱신"을 누를 때 Apps Script가 금융투자협회 FreeSIS "신용공여 잔고 추이"에서 유가증권(코스피) 신용거래융자 값을 받아 시트 `신용잔고` 탭에 쌓고 불러옵니다(시트가 비어 있으면 2년치, 이후엔 최근 3주를 덮어써 정정 반영).
  - 준비: `apps_script.gs.txt` 새 코드를 붙여넣고 **배포 관리 → 새 버전**으로 배포합니다(외부 요청 권한 승인 창이 뜨면 허용). 매일 저녁 7시에 대시보드를 열지 않아도 쌓이게 하려면 편집기에서 **setupCreditTrigger**를 한 번 실행하세요. **updateCredit**을 직접 실행해 시험해 볼 수 있습니다.
- 자동 수집이 안 될 때는 예전처럼 금융투자협회(freesis.kofia.or.kr) 등에서 받은 엑셀/CSV를 탭에서 올립니다. 날짜 열과 "신용융자 잔고(유가증권)" 열을 자동으로 찾고 단위(원·백만원·억원)는 값 크기로 판단해 조원으로 바꿉니다.
- 동기화(Apps Script)를 설정했다면 올린 값이 구글 시트 `신용잔고` 탭(A열 날짜, B열 조원)에도 저장되어 다른 기기에서 "시트에서 불러오기"로 받을 수 있습니다. 이 기능을 쓰려면 Apps Script를 새 버전으로 다시 배포하세요(`apps_script.gs.txt`).
- 주가 이력은 RS 탭과 같은 방식(GOOGLEFINANCE)으로 가져옵니다.

### 관련 종목 비교 (종목분석 탭 아래쪽, 예전 "분석" 탭을 합침)
- 위에서 고른 종목이 기준입니다. "자동 추천 (관련 3종목)"을 누르면 Claude가 관련 종목 3개를 골라 수익률(기간 시작일 = 0%)을 한 그래프에 겹쳐 그립니다. 기간은 종목분석 탭의 기간 선택을 따릅니다.
- 검색 칸에 종목명이나 구글 티커(VLO, KRX:010950 등)를 넣고 "더하기"로 직접 추가할 수도 있습니다(보유 종목이 아니어도 됨). 칩의 ✕를 누르면 빠집니다. 기준 종목을 바꾸면 이전 추천은 지워집니다.
- 자동 추천은 Apps Script가 Claude API를 호출합니다. 준비: Apps Script 프로젝트 설정 > 스크립트 속성에 `ANTHROPIC_API_KEY`를 추가하고, `apps_script.gs.txt`로 새 버전을 배포(외부 요청 권한 승인 1회). 키가 없거나 호출이 실패하면 앱 안의 업종표(`PEER_GROUPS`)로 대신 고릅니다.
- 시세는 RS 탭과 같은 방식(GOOGLEFINANCE)으로 가져오며 최대 1년입니다.
