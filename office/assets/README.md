# 주식 사무실 비주얼 가이드

## 환경 시안

`office-concepts-v1.png`의 왼쪽부터 다음 방향입니다.

1. 금융 리서치 오피스
   - 흰색과 밝은 석재, 청록색 포인트
   - 현재 대시보드와 색상 연결이 가장 자연스러움
   - 시세 모니터와 기능별 작업 위치가 가장 또렷함
2. 투자 라이브러리
   - 밝은 원목, 크림색 벽, 책장과 황동 장식
   - 장시간 머무르는 개인 투자실에 적합
   - 따뜻하고 차분하지만 화면 정보 대비를 별도로 확보해야 함
3. 도시형 포트폴리오 스튜디오
   - 회색과 흰색, 유리 파티션, 올리브색 가구
   - 가장 현대적이고 넓어 보이는 구성
   - 모바일 축소 화면에서 작은 장식이 뭉치지 않도록 단순화 필요

### 실제 적용 배경

- `office-financial-research-v2.png`: 인물을 제거하고 가로형 2D 도트 화면으로 다시 제작한 금융 리서치 오피스입니다.
- `office/index.html`의 실제 사무실 배경으로 적용했습니다.
- 이미지 로딩에 실패하면 기존 코드 기반 사무실 배경이 폴백으로 표시됩니다.

## 캐릭터 기준

`assistant-character-guide-v1.png`를 비서 캐릭터의 외형 기준으로 사용합니다.

- 원본 백업: `archive/assistant-character-guide-v1-backup.png`
- 2D 도트 비율 비교 시안: `assistant-character-pixel-v2-preview.png`
- v2 시안은 약 2.7등신, 머리 약 37%, 짧은 몸통과 팔다리를 기준으로 합니다.
- v2 시안은 `office/index.html`의 정면·측면·후면·걷기 캐릭터에 적용되었습니다.
- 기존 캐릭터 코드는 새 이미지 로딩 실패 시 표시되는 폴백으로 유지합니다.

- 모든 자세에서 같은 얼굴, 머리 모양, 체형과 복장을 유지합니다.
- 기본 복장은 남색 재킷, 미색 셔츠, 차콜색 바지입니다.
- 정면, 측면, 후면은 이동 방향에 사용합니다.
- 걷기 자세는 자리 이동 애니메이션에 사용합니다.
- 컴퓨터, 보고서, 차트 설명 자세는 작업별 상태에 사용합니다.
- 실제 화면용 자산은 각 자세를 별도의 투명 PNG로 제작합니다.
- 작은 화면에서도 얼굴이 읽히도록 최종 표시 높이는 최소 56px을 기준으로 합니다.
- 현재 도트 캐릭터는 새 자산이 모두 준비될 때까지 예비 표시로 유지합니다.

## 구현 원칙

- 현재 대시보드, 백테스트, 재무 위치와 이동 경로는 유지합니다.
- 장식보다 작업 위치와 비서의 상태가 먼저 보이도록 합니다.
- PC와 모바일에서 같은 배경을 사용하되 모바일에서는 가구 세부 묘사를 줄입니다.
- 생성 이미지의 글자와 차트는 장식용으로 사용하지 않고 실제 HTML 텍스트와 캔버스 그래프로 다시 그립니다.
