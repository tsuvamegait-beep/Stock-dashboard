Google Sheets 연결

새 Google Sheet 열기 ↗ · 읽기 전용 공개 URL입니다. EIA API 키는 Apps Script의 스크립트 속성에만 저장합니다. 자동 수집은 서울시간 매일 19시 실행되며, 페이지를 열지 않아도 시트에 기록됩니다.

처음 설정하는 방법
  1. 연결된 Google Sheet의 여섯 탭은 이미 준비됐습니다. 새 Apps Script 프로젝트를 만듭니다.
  2. oil/apps_script.gs.txt를 붙여넣고 스크립트 속성 EIA_API_KEY를 넣습니다.
  3. setupOilMonitor를 한 번 실행해 시트와 매일 트리거를 만듭니다.
  4. 웹 앱으로 배포한 URL을 위에 입력합니다. 실행 계정은 본인, 액세스는 모든 사용자로 설정합니다.
  5. 러시아·VLO 값은 시트의 해당 탭에 관측일, 값, 원문 URL, 발표일을 입력합니다.

매일 저장 기록

행의 날짜는 수집일입니다. 각 지표의 실제 관측일은 위 카드에 따로 표시합니다. 같은 날 다시 수집하면 기존 행을 갱신합니다.

지표 해석

ULSD 크랙은 EIA의 디젤·WTI 현물 가격으로 계산한 대용 지표입니다. EIA 주간 재고는 금요일 기준 관측값이며 발표일이 다릅니다. 러시아 수출과 VLO 실현 마진은 EIA 자료가 아니므로 별도 원문 입력이 필요합니다. 오래된 값은 새 시장 신호로 취급하지 않습니다.
