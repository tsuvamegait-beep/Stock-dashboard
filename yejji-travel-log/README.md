# Yejji Travel Log

예찌와 한원의 여행 장면을 독립적으로 관리하는 정적 웹 프로젝트입니다. 상하이 동방명주와 미야코지마 스노클링 장면을 탭으로 전환합니다.

## 독립 구조

- `index.html`: 화면, 스타일, 캐릭터 동작을 모두 포함한 진입 파일
- `assets/`: 여행 배경과 예찌·한원 캐릭터 이미지
- 외부 패키지나 빌드 과정 없음

폴더 자체만 별도 GitHub 저장소의 루트로 복사해도 실행됩니다. 현재 `index.html`의 Office 복귀 링크(`../office/`)만 기존 Stock Dashboard와 연결되어 있으므로, 저장소를 분리할 때 해당 링크를 새 주소로 바꾸거나 제거하면 됩니다.

## 로컬 확인

이 폴더의 상위 경로에서 정적 서버를 실행한 뒤 `/yejji-travel-log/`를 엽니다. 미야코지마를 바로 열려면 `/yejji-travel-log/#miyakojima`를 사용합니다. GitHub Pages에서는 저장소 루트 또는 하위 경로에 그대로 게시할 수 있습니다.
